Analysis listens to Spotify's own output through a virtual loopback device, so it measures the exact master you'll hear — full length, not a preview. See the README for the one-time routing setup on macOS / Windows / Linux.

Playlist

Track analysis is stored once for the whole server, not per account — tempo and loudness are properties of the recording. A track analysed by anyone is analysed for everyone. Only your tempo reference and the energy weighting are personal.

Tempo detection can lock onto a different grouping of the same pulse (half, double, or dotted time) — click any BPM value to correct it. An asterisk marks a manually set tempo, which is preserved if you re-analyze.
